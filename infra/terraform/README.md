# Terraform: AWS deployment

Creates, in the default VPC of the chosen region:

- RDS PostgreSQL (private, encrypted). The master password is generated by AWS and kept in Secrets Manager.
- An EC2 host (Amazon Linux 2023) that clones this repo, builds the Docker image and runs the dashboard on port 8501.
- Security groups: the dashboard port is open only to `allowed_cidrs`; PostgreSQL accepts traffic only from the dashboard host.
- An IAM role that allows Session Manager access and reading the database secret. There is no SSH port or key pair.

## Use

```bash
cd infra/terraform
cp terraform.tfvars.example terraform.tfvars   # set allowed_cidrs to your IP/32
terraform init
terraform plan
terraform apply
```

Open the `dashboard_url` output after a minute or two. The dashboard will be empty until data is loaded. Get a shell with `aws ssm start-session --target <instance_id>`, then run the ETL container against the RDS database with the `DB_*` variables the dashboard container uses.

## Cost and cleanup

The EC2 instance and the RDS instance are billed while they exist. Remove everything with `terraform destroy`. Do not commit `terraform.tfvars` or state files (both are in `.gitignore`).
